# Day 3 — Personal Blog & Portfolio

A responsive personal blog and portfolio website created using HTML5 and CSS3 as part of the Web Development Day 3 assignment.

## About the Project

This project is a personal website that introduces me, showcases my projects, and shares my learning journey as a first-year B.Tech Computer Science and Engineering student at Invertis University.

The website focuses on semantic HTML, navigation links, images, lists, and responsive web design.

## Work Completed

- Created three connected pages: `index.html`, `about.html`, and `blog.html`.
- Added a shared navigation bar to move between the pages.
- Used semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`.
- Added images using relative paths and meaningful `alt` attributes.
- Used ordered and unordered lists to organize information.
- Added external links that open in a new tab.
- Created project cards to showcase my learning and development work.
- Added a learning section describing my current technical interests.
- Styled the website using CSS3.
- Used responsive layouts to improve the experience on different screen sizes.

1. Clone or download this repository.
2. Keep the HTML files, `styles.css`, and `images` folder together.
3. Open `index.html` in any modern web browser.
4. Navigate between Home, About, and Blog to explore the website.
